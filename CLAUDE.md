This folder contains instructions to add additional VC deals to the European VC radar. The goal is to provide an opensource overview of deals and to be the most complete overview. As a result, it is important that at least all the Tier 1 sources in the 'Vc radar monthly scrape' file in Context are being scraped for new deals. 

Please follow the instructions as described in the SKILL.md file that is linked to the scratchpad of this project.

Only add belows of EUR 500k of more to Supabase and include the closing date. 

For the infographic, please use the same layout and design as www.vcradar.nl

Please select the model suitable for each of the activities, balancing scraping the most deals as possible but using as little as possible tokens.
